# RPA Orchestrator

Aplicação Vite + React + react-router-dom para orquestração e monitoramento de RPA.

## Como rodar

```bash
npm install
npm run dev
```

Build de produção: `npm run build`

## Estrutura

- `src/pages/` — Home, Dashboard, RPA, Configurações
- `src/components/` — Sidebar, Header, StatCard, StatusBadge
- `src/lib/mock-data.js` — dados mockados
